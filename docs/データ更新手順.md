# 店舗データの更新手順

## データの流れ

```
bookoff.co.jp の店舗ページ
   │  ~/claude/bookoff-shop-data/scrape.py（0.7秒間隔でページ取得・pages/ にキャッシュ）
   ├─→ Googleスプレッドシート bookoff_data ──→ CSV書き出し ──→ data/source/*.csv
   └─→ coords.csv（公式ピンの緯度経度）
                                                    │
                       npm run build:stores ────────┘
                                   ↓
                       public/bookoff-stores.csv（アプリが読む生成物）
```

- **店舗の素データ**（ID・名前・住所・営業時間・電話・規模・駐車場）の正はスプレッドシート `bookoff_data`。
  その書き出しを `data/source/` に置く。
- **座標**の正は店舗ページのルート案内リンク（`maps.google.com/maps?daddr=緯度,経度`）。
  住所からのジオコーディングより正確なので、必ずこちらを使う。
- `public/bookoff-stores.csv` は生成物。手で編集しない。

## 更新のしかた

### 1. 店舗ページを取り直す

```bash
cd ~/claude/bookoff-shop-data
python3 scrape.py ids_current.txt
python3 export_coords.py
```

`pages/` にキャッシュがある店舗は取りに行かない。**取り直したい店舗はキャッシュを消す**:

```bash
rm ~/claude/bookoff-shop-data/pages/shop20013.html
```

### 2. ニューオープン店を足す

新店には新しい `store_ID` が振られる。連番スイープでIDを掃いて、
`ids_current.txt` に追記してから 1. を実行する。
`store_ID` の先頭桁がそのまま種別になる（**2番台＝直営 / 1番台＝フランチャイズ**）ので、
種別を手で入力する必要はない。

スプレッドシート側にも新店の行を足し、書き出しを `data/source/` に上書きする。

### 3. 生成する

書き出した `coords.csv` を、このリポジトリにコピーしてから生成する。
`~/claude/bookoff-shop-data` はGit管理外なので、**座標の控えはこちら側に置く**。

```bash
cd ~/claude/stamp-rally
cp ~/claude/bookoff-shop-data/coords.csv data/source/coords.csv
npm run build:stores
```

実行すると前回の出力との差分が出る:

```
差分: 新規 2 / 消滅 1 / 変更 3
  [新規] 20999 BOOKOFF ○○店
  [消滅] 20146 BOOKOFF 横浜東戸塚店
  [変更] 20013 BOOKOFF 青梅店
         営業時間: 10:00～21:00 → 10:00～20:00
```

差分を確認してからコミットする。

### 4. 公開する

```bash
cd ~/claude/stamp-rally
git add -A && git commit -m "店舗データ更新"
git push
```

`main` に push すると GitHub Actions がビルドして公開する。

## 座標がおかしいとき

現地で「店の前にいるのにスタンプが押せない」場合（判定は半径100m）、
`data/coords-overrides.json` に手動補正を書く。**ここに書いた座標が何より優先**され、
再生成しても上書きされない。

```json
{
  "20013": { "lat": 35.78688, "lng": 139.30368, "memo": "移転後の位置。2026-08-13 現地確認" }
}
```

## 座標の予備手段

公式ピンが取れない店舗（ページが消えた等）は、住所から国土地理院APIで引く。
その結果のうち番地まで当たらなかったものは `scripts/.geocode-coarse.txt` に出る。
数百mずれている可能性があるので、現地で確認したら上の手動補正に書く。
